## Reproduced defects and exact correction boundaries

1. **COD after checkout TTL:** collection could succeed while the historical consumption filter silently excluded its expired physical reservation. The new exception is bound to a live COD order and its original line/product/variant/warehouse; online expiry remains strict.
2. **Physical/nonphysical mismatch:** binding demanded reservations for backorders, and payment quarantined wholly nonphysical orders. Checkout now captures the actual allocation result before first order insert; binding and payment read the same immutable snapshot. Quantity coverage and reservation-lineage validation remain exact.
3. **Caller-supplied binding lineage:** a foreign order ID or substituted warehouse on supplied lines previously bound successfully. Persisted canonical order lines now own this decision.
4. **Delivered-proof owner bypass:** the early already-delivered branch previously accepted proof from an unauthorized source. It now applies the same fulfillment-owner boundary before replay/backfill.
5. **Returned but still reserved / shipment still Delivered:** fulfillment return previously had neither unconsumed-hold release nor Manual original-shipment return progression. Both now occur in the canonical transaction, without committed-stock restoration or financial mutation.
6. **Customer status downgrade:** an existing API response was `Completed /Delivered /Settled`, but the tracking page rendered “Order Placed.” Its adapter omitted Completed and ignored independent shipping progression. The adapter now uses authorized logistics states, preserves cancellation and localizes returned/failed states in English/Arabic. It never uses payment as delivery proof.

Production paths changed: `PointOfSale.API/Services/Checkout/CheckoutService.cs`; new `PointOfSale.Core/Policies/OrderInventoryReservationSnapshot.cs`; `PointOfSale.Infrastructure/Data/Repositories/ProductVariantStockRepository.cs`; `PointOfSale.Infrastructure/Reliability/ProductVariantInventoryLineageAuthority.cs`; `PointOfSale.Infrastructure/Payments/PaymentLifecycleService.cs`; `PointOfSale.Infrastructure/Fulfillment/OrderFulfillmentService.cs`; Storefront `src/hooks/useOrder.ts`, `src/types/order.ts` and English/Arabic locale JSON.
