## Canonical Authority Matrix

| Pricing concept | Canonical authority | Compatibility / derivative fields | Source-code evidence |
|---|---|---|---|
| Simple product selling price | Default `ProductUnit.SellingPrice` | `Product.SalePrice` is mirror only; Mongo/search prices are projections | `CatalogPricingAuthority.ResolveSimpleSellingPrice`; manual order resolver uses `CatalogPricingAuthority.ResolveSimpleSellingPrice(configuredUnit)` |
| Simple product purchase/cost price | Default `ProductUnit.PurchasePrice` | `Product.PurchasePrice` and simple default variant `CostPrice` are mirrors | Purchase and return flows update default unit then call `ProductPricingCompatibilityMirror.MirrorSimpleProductFromDefaultUnit` |
| Variant sale/base price | `ProductVariant.Price` | Read models/search documents are projections | `CatalogPricingAuthority.ResolveVariantSellingPrice`; `ProductVariant` entity declares variant prices canonical |
| Variant online price | `ProductVariant.OnlinePrice` when positive, else `ProductVariant.Price` | CommerceHub base price derives from variant effective price | `CatalogPricingAuthority.ResolveVariantOnlinePrice`; `CommerceHubPriceAuthority.ResolveBaseVariantPrice` |
| Variant cost price | `ProductVariant.CostPrice` | Purchase/order cost snapshots are transaction records | `CatalogPricingAuthority.ResolveVariantPurchasePrice`; purchases recalculate `variant.CostPrice` |
| CommerceHub channel override | `CommerceHubListing.CommerceHubPrice` only when runtime policy accepts it | CommerceHub final price is channel-specific and does not rewrite catalog authorities | `CommerceHubPriceAuthority` returns `CommerceHubPriceSource.CommerceHubOverride` only for accepted overrides |
| Product price fields | No business pricing authority | Temporary compatibility mirrors only | `ProductPricingCompatibilityMirror` is the only live mirror component; `PricingAuthorityConsolidationCertificationTests` enforces the boundary |

## Migrated Readers

| Reader | Previous ambiguity | Current authority |
|---|---|---|
| Manual order pricing | Product online/sale fallback | Default unit for simple products; variant effective price for variant products |
| Affiliate eligibility | Product online/sale fallback before units | Default-unit price for simple products; variant effective price for variant products |
| POS quick search / quick access | Product mirror prices exposed as live prices | Default-unit purchase/selling prices for simple product rows; variant prices for variant rows |
| Product response mapper | Product mirror values returned as DTO prices | Default-unit values returned through legacy DTO fields |
| Mongo/search rebuild fallback | Product mirror fallback | Default-unit price for simple products; variant price for variant products |

## Classification Summary

Canonical live catalog authorities currently exist in more than one place:

| Surface | Authority |
|---|---|
| POS configured unit selling price | SQL `ProductUnits.SellingPrice` |
| POS variant fallback selling price | SQL `ProductVariants.Price` |
| Storefront simple-product price | SQL `ProductUnits.SellingPrice` projected to `ProductDocument.DefaultUnit.SalePrice` |
| Storefront variant checkout price | SQL `ProductVariants.OnlinePrice` if positive, else `ProductVariants.Price` |
| CommerceHub base price | SQL `ProductVariants.OnlinePrice` if positive, else `ProductVariants.Price` |
| CommerceHub channel override | SQL `CommerceHubListings.CommerceHubPrice` when enabled |
| Cost authority | SQL `ProductVariants.CostPrice`, updated by purchase/return flows |
| Product-level `SalePrice` / `OnlinePrice` / `PurchasePrice` | Live simple-product compatibility mirror and fallback, not dead legacy |
