## Final Authority Collision Summary

Certification fails on the cost/purchase-price axis:

- `ProductVariant.CostPrice`: Product Authoring writes the same canonical field that Purchasing and Purchase Returns recalculate.
- `ProductUnit.PurchasePrice`: Product Authoring writes the unit field and Purchasing/Purchase Returns mirror cost into it.

These fields do not belong to exactly one bounded context in the current source.
