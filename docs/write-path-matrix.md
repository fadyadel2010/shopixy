# Product Write Path Matrix

Date: 2026-07-30

Legend:

- `Correct Authority`: follows the observed canonical Product Authoring or designated domain authority.
- `Wrong Authority`: mutates Product canonical state from an incorrect authority.
- `Shared Authority`: mutates Product-related state from a separate domain authority.
- `Compatibility Authority`: maintains legacy or mirror state.
- `Infrastructure Only`: projection, repair, seed, or background infrastructure.
- `Forbidden`: not allowed in production architecture.
