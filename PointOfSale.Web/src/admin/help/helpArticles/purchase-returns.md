# Purchase Returns

## English

### Overview

The Purchase Returns page is used when products are sent back to a supplier after purchase. It helps you record the returned quantities, connect them to the original purchase invoice, and decide whether the value should return as cash, visa, or supplier credit.

### When to use this page

Use this page when goods arrive damaged, incorrect, over-supplied, or when a supplier agrees to take items back after a purchase was already recorded.

### Steps

Open a new purchase return and choose the supplier, warehouse, and return date. Load the original purchase invoice whenever available so the items appear automatically. Enter the quantities being returned, review the unit price and tax, and add a reason for the return. Choose how the refund should be handled, then save the return and review the total before leaving the page.

### Tips

Return only the lines and quantities the supplier has approved.

### Common mistakes

Creating a return without checking the original invoice quantities first.

## العربية

### نظرة عامة

تُستخدم صفحة مرتجعات الشراء عندما يتم إرجاع منتجات إلى المورد بعد تسجيل عملية الشراء. تساعدك الصفحة على تسجيل الكميات المرتجعة، وربطها بفاتورة الشراء الأصلية، وتحديد هل ستعود القيمة نقدًا أو على فيزا أو كرصيد للمورد.

### متى تستخدم هذه الصفحة

استخدم هذه الصفحة عندما تصل بضاعة تالفة أو غير صحيحة أو بكميات زائدة، أو عندما يوافق المورد على استرجاع أصناف بعد أن تكون فاتورة الشراء قد سُجلت بالفعل.

### طريقة الاستخدام

افتح مرتجع شراء جديد وحدد المورد والمخزن وتاريخ المرتجع. حمّل فاتورة الشراء الأصلية كلما كانت متاحة حتى تظهر الأصناف تلقائيًا. أدخل الكميات التي سيتم إرجاعها، وراجع سعر الوحدة والضريبة، ثم أضف سبب المرتجع. اختر طريقة معالجة قيمة المرتجع، ثم احفظ العملية وراجع الإجمالي قبل مغادرة الصفحة.

### نصائح

أرجع فقط السطور والكميات التي وافق المورد عليها.

### أخطاء شائعة

إنشاء مرتجع بدون مراجعة كميات فاتورة الشراء الأصلية أولًا.
