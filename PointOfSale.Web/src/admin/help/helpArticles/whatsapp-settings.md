# WhatsApp Settings

## English

### Overview

This page is the main place for managing your store's WhatsApp setup. It is used to connect accounts, review connection status, manage message templates, monitor safety controls, and check sending activity before using WhatsApp features across the store.

### When to use this page

Open this page when setting up a new WhatsApp account, reconnecting a disconnected number, updating message templates, checking delivery activity, or pausing sending if something unusual happens.

### Steps

1. Go to the accounts section and create or review a WhatsApp account.
2. Open the QR code and connect the phone if needed.
3. Check the account status before using it in store workflows.
4. Review or edit templates used for customer messages.
5. Check safety tools and logs if messages stop or errors appear.

### Tips

Confirm the account is connected before turning on features that depend on WhatsApp.

### Common mistakes

Using a disconnected account, forgetting to review templates, or changing settings without checking message safety status.

## العربية

### نظرة عامة

هذه الصفحة هي المكان الرئيسي لإدارة إعدادات واتساب الخاصة بمتجرك. تُستخدم لربط الحسابات، ومراجعة حالة الاتصال، وإدارة قوالب الرسائل، ومتابعة أدوات الأمان، وفحص النشاط قبل تشغيل أي ميزة تعتمد على واتساب.

### متى تستخدم هذه الصفحة

افتح هذه الصفحة عند إعداد رقم جديد، أو إعادة ربط رقم مفصول، أو تعديل قوالب الرسائل، أو مراجعة نشاط الإرسال، أو إيقاف الإرسال إذا ظهرت مشكلة غير معتادة.

### طريقة الاستخدام

1. اذهب إلى قسم الحسابات وأنشئ حساب واتساب جديدًا أو راجع الحساب الحالي.
2. افتح رمز QR واربط الهاتف إذا لزم الأمر.
3. تأكد من أن حالة الحساب متصلة قبل استخدامه في المتجر.
4. راجع أو عدّل القوالب المستخدمة في رسائل العملاء.
5. افحص أدوات الأمان والسجلات إذا توقف الإرسال أو ظهرت أخطاء.

### نصائح

تأكد من أن الحساب متصل فعلًا قبل تفعيل أي ميزة تعتمد على واتساب.

### أخطاء شائعة

استخدام حساب غير متصل، أو نسيان مراجعة القوالب، أو تعديل الإعدادات بدون التحقق من حالة الأمان.
