# Treasury Opening Balance

## English

### Overview

The Treasury Opening Balance page is used to enter the cash amount already available in the selected cash register before normal daily work begins. This gives the system a clear starting point so later sales, payments, and treasury movements are easier to follow.

### When to use this page

Use this page when setting up a new store, starting the system for the first time, or entering the initial cash that already exists before live transactions are recorded.

### Steps

Choose the correct cash register first. Check whether an opening balance is already saved for it. If no amount exists yet, enter the available cash, select the correct date, and add a short note if needed. Save the record, then review the saved amount to make sure the right cash register received the correct opening value.

### Tips

Confirm the real cash on hand before typing the amount.

### Common mistakes

Saving the opening amount under the wrong cash register.

## العربية

### نظرة عامة

تُستخدم صفحة الرصيد الافتتاحي للخزينة لإدخال المبلغ النقدي الموجود فعليًا في درج النقد أو الخزينة قبل بدء العمل اليومي. هذا يمنح النظام نقطة بداية واضحة حتى تصبح المبيعات والمدفوعات وحركات الخزينة لاحقًا أسهل في المتابعة.

### متى تستخدم هذه الصفحة

استخدم هذه الصفحة عند إعداد متجر جديد، أو عند تشغيل النظام لأول مرة، أو عند تسجيل المبلغ النقدي الموجود بالفعل قبل بدء المعاملات الفعلية.

### طريقة الاستخدام

اختر الخزينة الصحيحة أولًا. تحقق مما إذا كان قد تم حفظ رصيد افتتاحي لها من قبل. إذا لم يوجد مبلغ سابق، أدخل النقد المتاح، وحدد التاريخ الصحيح، وأضف ملاحظة قصيرة إذا لزم الأمر. احفظ السجل، ثم راجع المبلغ المحفوظ للتأكد من أنه تم تسجيله في الخزينة الصحيحة.

### نصائح

تأكد من النقد الموجود فعليًا قبل إدخال الرقم.

### أخطاء شائعة

حفظ الرصيد الافتتاحي في خزينة مختلفة عن الخزينة المقصودة.
