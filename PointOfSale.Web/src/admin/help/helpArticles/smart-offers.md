# Smart Offers

## English

### Overview

This page manages popup-style marketing offers for moments such as exit intent, timed prompts, and other on-site nudges. It helps you create targeted offers, monitor how many are active, and adjust messaging without changing your normal promotions list.

### When to use this page

Use this page when you want to stop visitors from leaving, push a limited incentive during browsing, or run a focused popup campaign around a specific customer behavior.

### Steps

1. Review the offers list and top summary cards.
2. Use search or status filters to find an offer quickly.
3. Click `Create Offer` to build a new smart offer.
4. Set the trigger, title, message, and any coupon or incentive details.
5. Save the offer and activate it when ready.
6. Return later to edit, pause, or remove it.

### Tips

Keep popup messages short and tied to one clear action for better results.

### Common mistakes

Running too many active popups, using unclear titles, or forgetting to pause offers after the campaign ends.

## العربية

### نظرة عامة

تُستخدم هذه الصفحة لإدارة العروض الذكية التي تظهر على شكل نوافذ منبثقة في لحظات محددة مثل نية الخروج أو التذكير بعد وقت معين. تساعدك على إنشاء عروض موجهة، ومتابعة عدد العروض النشطة، وتعديل الرسائل بدون التأثير على قائمة العروض التقليدية.

### متى تستخدم هذه الصفحة

استخدم هذه الصفحة عندما تريد تقليل مغادرة الزوار، أو تقديم حافز محدود أثناء التصفح، أو تشغيل حملة منبثقة مرتبطة بسلوك معين للعميل داخل الموقع.

### طريقة الاستخدام

1. راجع قائمة العروض وبطاقات الملخص.
2. استخدم البحث أو فلتر الحالة للوصول إلى العرض بسرعة.
3. اضغط `Create Offer` لإنشاء عرض جديد.
4. حدد نوع التفعيل والعنوان والرسالة وأي حافز أو كوبون مرتبط.
5. احفظ العرض ثم فعّله عند الجاهزية.
6. ارجع لاحقًا للتعديل أو الإيقاف أو الحذف.

### نصائح

اجعل رسالة النافذة قصيرة ومرتبطة بإجراء واحد واضح حتى تكون النتيجة أفضل.

### أخطاء شائعة

تشغيل عدد كبير من النوافذ معًا، أو استخدام عناوين غير واضحة، أو نسيان إيقاف العرض بعد انتهاء الحملة.
