# Units

## English

### Overview

The Units page defines the measurement units used by your products, such as piece, box, carton, kilo, or liter. Correct units make pricing, purchasing, inventory movement, and barcode workflows easier to manage with fewer mistakes.

### When to use this page

Open this page before creating products, when you start selling items in new packaging sizes, or when staff are using unclear unit names that cause confusion in invoices and stock transactions.

### How to use it

Check the existing unit list before adding anything new. Create only the units your store actually uses. Use simple names that your team understands immediately. If a unit name must change, update it carefully and make sure the new wording still matches how products are bought, sold, and counted in the warehouse.

### Tips

Use one name per unit instead of several similar versions.

### Common mistakes

Adding duplicate units like Box, box, and Boxes for the same meaning.

## العربية

### نظرة عامة

تحدد صفحة الوحدات وحدات القياس المستخدمة مع المنتجات مثل قطعة، علبة، كرتونة، كيلو، أو لتر. الوحدات الصحيحة تجعل التسعير والشراء وحركة المخزون والطباعة أسهل وأقل عرضة للأخطاء.

### متى تستخدم هذه الصفحة

افتح هذه الصفحة قبل إنشاء المنتجات، أو عند بدء بيع أصناف بأحجام تعبئة جديدة، أو عندما يستخدم الفريق أسماء وحدات غير واضحة تسبب ارتباكًا في الفواتير وحركة المخزون.

### طريقة الاستخدام

راجع قائمة الوحدات الحالية قبل إضافة أي وحدة جديدة. أنشئ فقط الوحدات التي يستخدمها متجرك فعليًا. استخدم أسماء بسيطة يفهمها الفريق مباشرة. وإذا احتجت لتعديل اسم وحدة، فقم بذلك بحذر وتأكد أن الاسم الجديد يطابق طريقة شراء المنتج وبيعه وعدّه داخل المخزن.

### نصائح

استخدم اسمًا موحدًا لكل وحدة بدلًا من عدة تسميات متقاربة.

### أخطاء شائعة

إضافة وحدات مكررة مثل علبة وعلب وعلبة كبيرة لنفس الاستخدام الأساسي.
