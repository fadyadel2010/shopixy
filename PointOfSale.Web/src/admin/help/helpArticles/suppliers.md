# Suppliers

## English

### Overview

The Suppliers page is used to keep a clean list of the businesses and vendors you buy from. It helps you save supplier contact details, track balances, and maintain accurate records for purchasing, returns, and payment follow-up.

### When to use this page

Use this page before creating purchase invoices, when a supplier changes contact details, when reviewing who you owe money to, or when you need a reliable supplier record for reports and accounting screens.

### How to use it

Search for the supplier before adding a new record. If the supplier is missing, create it with the correct name, phone number, address, and notes. Edit existing records when details change. Review the balance area before recording payments so you understand the current financial position with that supplier.

### Tips

Store the official supplier name exactly as it appears on invoices.

### Common mistakes

Adding the same supplier twice with slightly different spelling.

## العربية

### نظرة عامة

تُستخدم صفحة الموردين للاحتفاظ بقائمة مرتبة للشركات والموردين الذين تشتري منهم. تساعدك الصفحة على حفظ بيانات الاتصال، متابعة الأرصدة، والحفاظ على سجلات دقيقة للمشتريات والمرتجعات والتحصيلات.

### متى تستخدم هذه الصفحة

استخدم هذه الصفحة قبل إنشاء فاتورة شراء، أو عند تغيير بيانات المورد، أو عند مراجعة المبالغ المستحقة عليه أو له، أو عندما تحتاج سجلًا صحيحًا للتقارير والحسابات.

### طريقة الاستخدام

ابحث عن المورد أولًا قبل إنشاء سجل جديد. إذا لم تجده، أضفه بالاسم الصحيح ورقم الهاتف والعنوان والملاحظات. عدّل السجل الحالي عند تغير البيانات. راجع خانة الرصيد قبل تسجيل أي دفعة حتى تعرف الموقف المالي الحالي مع هذا المورد.

### نصائح

احفظ الاسم الرسمي للمورد كما يظهر في الفواتير.

### أخطاء شائعة

إضافة المورد نفسه أكثر من مرة بسبب اختلاف بسيط في كتابة الاسم.
