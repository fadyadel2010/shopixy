# Pixel Tracking

## English

### Overview

This page controls the conversion value sent from your store to advertising platforms. It helps you decide whether to send the full order value, a fixed value, or a percentage-based value for selected platforms, while keeping your internal revenue reports unchanged.

### When to use this page

Use this page when you want to adjust advertising signal values, test a reporting strategy, or limit which platforms receive a special conversion value.

### Steps

1. Review the warning note at the top.
2. Turn pixel override on or off.
3. Choose the strategy: percentage or fixed amount.
4. Enter the value you want to send.
5. Select the platforms that should use this rule.
6. Check the preview and then save.

### Tips

Use the preview before saving so you understand how the sent value will change for a typical order.

### Common mistakes

Confusing ad-platform values with real sales reports, choosing the wrong strategy, or forgetting which platforms are selected.

## العربية

### نظرة عامة

تتحكم هذه الصفحة في قيمة التحويل التي يرسلها المتجر إلى منصات الإعلانات. تساعدك على تحديد ما إذا كنت سترسل القيمة الكاملة للطلب أو قيمة ثابتة أو نسبة مئوية لمنصات محددة، مع بقاء تقارير الإيرادات الداخلية كما هي بدون تغيير.

### متى تستخدم هذه الصفحة

استخدم هذه الصفحة عندما تريد تعديل قيمة الإشارة الإعلانية، أو تجربة طريقة مختلفة للتقارير، أو تحديد منصات معينة تستقبل قيمة تحويل خاصة.

### طريقة الاستخدام

1. راجع التنبيه الظاهر أعلى الصفحة.
2. فعّل أو أوقف التعديل الخاص بالبيكسل.
3. اختر الطريقة: نسبة مئوية أو مبلغ ثابت.
4. أدخل القيمة التي تريد إرسالها.
5. اختر المنصات التي سيطبق عليها هذا الإعداد.
6. راجع المعاينة ثم احفظ.

### نصائح

استخدم المعاينة قبل الحفظ حتى تفهم كيف ستتغير القيمة المرسلة لطلب نموذجي.

### أخطاء شائعة

الخلط بين القيم المرسلة للإعلانات وبين تقارير المبيعات الحقيقية، أو اختيار طريقة غير مناسبة، أو نسيان المنصات المحددة.
