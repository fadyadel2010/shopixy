# Suppliers Opening Balance

## English

### Overview

The Suppliers Opening Balance page is used to enter old balances that already existed with suppliers before the system went live. This helps supplier records reflect reality from the start and makes later payments and reports easier to trust.

### When to use this page

Use this page when setting up the system for the first time, when moving from paper or another program, or when supplier balances must be carried forward into the new system.

### Steps

Review the supplier list and identify only the suppliers with an existing balance. Choose the correct balance direction for each one, enter the amount, set the right date, and add a short note if it will help your team later. Save the new balances, then confirm the saved suppliers are marked as already set so you do not enter them twice.

### Tips

Check old supplier statements before entering any amount.

### Common mistakes

Recording the amount for the right supplier but choosing the wrong balance direction.

## العربية

### نظرة عامة

تُستخدم صفحة الرصيد الافتتاحي للموردين لإدخال الأرصدة القديمة الموجودة مع الموردين قبل تشغيل النظام فعليًا. هذا يجعل سجلات الموردين واقعية من البداية ويسهّل متابعة المدفوعات والتقارير لاحقًا.

### متى تستخدم هذه الصفحة

استخدم هذه الصفحة عند إعداد النظام لأول مرة، أو عند الانتقال من الورق أو من برنامج آخر، أو عندما تحتاج إلى ترحيل أرصدة الموردين إلى النظام الجديد.

### طريقة الاستخدام

راجع قائمة الموردين وحدد فقط الموردين الذين لديهم رصيد سابق. اختر نوع الرصيد الصحيح لكل مورد، ثم أدخل المبلغ وحدد التاريخ المناسب وأضف ملاحظة قصيرة إذا كانت ستفيد فريقك لاحقًا. احفظ الأرصدة الجديدة، ثم تأكد من أن الموردين المحفوظين أصبحوا مميزين على أنهم محفوظون مسبقًا حتى لا يتم إدخالهم مرة أخرى.

### نصائح

راجع كشف المورد القديم قبل إدخال أي مبلغ.

### أخطاء شائعة

تسجيل المبلغ للمورد الصحيح ولكن باختيار نوع رصيد غير صحيح.
