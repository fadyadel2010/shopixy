# Stock Transfers

## English

### Overview

This page is used to move products from one warehouse to another in an organized way. It lets the team create a transfer request, follow its status, and confirm when the move is approved and completed.

### When to use this page

Use this page when one branch needs stock from another branch, when you are balancing stock levels, or when a warehouse is preparing items for a seasonal demand change.

### Steps

1. Open `New Transfer`.
2. Select the sending warehouse and the receiving warehouse.
3. Add one or more products and enter the quantity for each item.
4. Add notes if the team needs special instructions.
5. Save the request and monitor its status in the list.
6. Approve, reject, or complete the transfer when the move is done.

### Tips

Add a short note about why the stock is moving so the team can review it later.

### Common mistakes

Choosing the same warehouse twice, adding the same product more than once, or marking a transfer complete before the items actually arrive.

## العربية

### نظرة عامة

تُستخدم هذه الصفحة لنقل الأصناف من مخزن إلى مخزن آخر بطريقة منظمة. تساعد الفريق على إنشاء طلب نقل، ومتابعة حالته، وتأكيده عند الموافقة عليه ثم اكتماله بعد وصول الأصناف.

### متى تستخدم هذه الصفحة

استخدم هذه الصفحة عندما يحتاج فرع إلى بضاعة من فرع آخر، أو عند موازنة الكميات بين المخازن، أو عند تجهيز مخزن لموسم بيع جديد.

### طريقة الاستخدام

1. افتح `New Transfer`.
2. اختر المخزن المرسل والمخزن المستلم.
3. أضف صنفًا واحدًا أو أكثر وحدد الكمية لكل صنف.
4. اكتب ملاحظات إذا كانت هناك تعليمات مهمة للفريق.
5. احفظ الطلب ثم تابع حالته من القائمة.
6. قم بالموافقة أو الرفض أو الإكمال بعد تنفيذ النقل فعليًا.

### نصائح

اكتب سبب النقل باختصار حتى يتمكن الفريق من مراجعته لاحقًا بسهولة.

### أخطاء شائعة

اختيار نفس المخزن كمرسل ومستلم، أو إضافة نفس الصنف مرتين، أو إنهاء الطلب قبل وصول الأصناف فعليًا.
