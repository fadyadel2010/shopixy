# Expense Categories

## English

### Overview

This page is where you organize your store expenses into clear groups such as rent, delivery, utilities, maintenance, or office supplies. Good categories make it easier to record expenses correctly and understand where money is going.

### When to use this page

Use this page before entering daily expenses, when you want to create a new spending group, or when an old category should be updated, hidden, or cleaned up.

### Steps

1. Review the current list of categories.
2. Click `Add Category` to create a new one.
3. Enter a clear name and short description.
4. Keep the category active if staff still need to use it.
5. Edit names when needed, or turn categories off if they should no longer appear.

### Tips

Keep category names simple and consistent so every employee records expenses the same way.

### Common mistakes

Creating duplicate categories, using vague names, or disabling a category that the team still needs for daily expense entry.

## العربية

### نظرة عامة

هذه الصفحة مخصصة لتنظيم مصروفات المتجر داخل مجموعات واضحة مثل الإيجار، التوصيل، الكهرباء، الصيانة، أو الأدوات المكتبية. وجود تصنيفات مرتبة يساعدك على تسجيل المصروفات بشكل صحيح ومعرفة أين تذهب الأموال بسهولة.

### متى تستخدم هذه الصفحة

استخدم هذه الصفحة قبل تسجيل المصروفات اليومية، أو عند الحاجة إلى إنشاء تصنيف جديد، أو تعديل اسم تصنيف قديم، أو إيقاف تصنيف لم يعد مستخدمًا.

### طريقة الاستخدام

1. راجع قائمة التصنيفات الحالية.
2. اضغط `Add Category` لإضافة تصنيف جديد.
3. اكتب اسمًا واضحًا ووصفًا قصيرًا.
4. اترك التصنيف نشطًا إذا كان الفريق سيستخدمه.
5. عدّل الاسم عند الحاجة أو أوقف التصنيف إذا لم يعد مطلوبًا.

### نصائح

استخدم أسماء بسيطة وثابتة حتى يسجل جميع الموظفين المصروفات بنفس الطريقة.

### أخطاء شائعة

إنشاء تصنيفات مكررة، أو استخدام أسماء غير واضحة، أو إيقاف تصنيف ما زال الفريق يحتاجه أثناء العمل اليومي.
