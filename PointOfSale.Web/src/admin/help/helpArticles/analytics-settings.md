# Analytics Settings

## English

### Overview

This page controls the external analytics connections used by your store, such as Google Analytics and Meta. It lets you enable providers, save connection details, run tests, and review whether each analytics destination is ready to receive store events.

### When to use this page

Open this page when you first connect analytics tools, when tracking stops, when you want to test a provider after updating details, or when launching a new marketing measurement setup.

### Steps

1. Review the provider cards and current status.
2. Enter or update the required connection details.
3. Save the settings.
4. Turn the provider on if you want it active.
5. Run the test connection action.
6. Review the result before relying on campaign reports.

### Tips

Test each provider after saving changes so you catch setup issues before spending budget on campaigns.

### Common mistakes

Saving details without testing, enabling a provider with incomplete data, or assuming external analytics is working because internal reports look correct.

## العربية

### نظرة عامة

تتحكم هذه الصفحة في ربط أدوات التحليلات الخارجية التي يستخدمها متجرك مثل Google Analytics وMeta. من خلالها يمكنك تشغيل المزودات، وحفظ بيانات الربط، وتشغيل اختبار الاتصال، والتأكد من أن كل جهة جاهزة لاستقبال أحداث المتجر.

### متى تستخدم هذه الصفحة

افتح هذه الصفحة عند ربط أدوات التحليل لأول مرة، أو عندما يتوقف التتبع، أو عندما تريد اختبار مزود بعد تحديث بياناته، أو عند إطلاق إعداد قياس تسويقي جديد.

### طريقة الاستخدام

1. راجع بطاقات المزودات وحالتها الحالية.
2. أدخل أو حدّث بيانات الربط المطلوبة.
3. احفظ الإعدادات.
4. فعّل المزود إذا كنت تريد تشغيله.
5. شغّل اختبار الاتصال.
6. راجع النتيجة قبل الاعتماد على تقارير الحملات.

### نصائح

اختبر كل مزود بعد الحفظ حتى تكتشف مشكلات الإعداد قبل إنفاق الميزانية على الحملات.

### أخطاء شائعة

حفظ البيانات بدون اختبار، أو تشغيل مزود ببيانات ناقصة، أو افتراض أن التحليلات الخارجية تعمل فقط لأن التقارير الداخلية تبدو صحيحة.
