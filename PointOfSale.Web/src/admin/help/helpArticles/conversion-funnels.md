# Conversion Funnels

## English

### Overview

This page shows the main customer journeys in your online store, such as browsing, cart, checkout, and purchase funnels. It helps you see where shoppers move forward and where they stop, so you know which stage needs improvement.

### When to use this page

Open this page when sales are weaker than expected, when you want to compare different funnel paths, or when you need to decide whether the biggest problem is discovery, cart building, checkout, or final purchase.

### Steps

1. Review the list of available funnels.
2. Check the funnel name, description, and number of steps.
3. Open the funnel that matches the journey you want to study.
4. Compare stages to find where customers drop off most.
5. Use what you learn to improve store pages, offers, or checkout flow.

### Tips

Start with the purchase or checkout funnel first because it usually shows the clearest sales blockers.

### Common mistakes

Looking at one funnel only, ignoring drop-off between steps, or changing many things before confirming where customers are leaving.

## العربية

### نظرة عامة

تعرض هذه الصفحة المسارات الرئيسية التي يمر بها العميل داخل المتجر مثل التصفح والسلة والدفع والشراء. تساعدك على معرفة أين يتقدم العميل وأين يتوقف، حتى تحدد المرحلة التي تحتاج إلى تحسين.

### متى تستخدم هذه الصفحة

افتح هذه الصفحة عندما تكون المبيعات أقل من المتوقع، أو عندما تريد مقارنة أكثر من مسار، أو عندما تحتاج إلى معرفة ما إذا كانت المشكلة في الاكتشاف أو السلة أو الدفع أو الشراء النهائي.

### طريقة الاستخدام

1. راجع قائمة المسارات المتاحة.
2. افحص اسم كل مسار ووصفه وعدد الخطوات فيه.
3. افتح المسار الذي يطابق الرحلة التي تريد دراستها.
4. قارن بين المراحل لمعرفة أين يخرج العملاء أكثر.
5. استخدم النتيجة لتحسين صفحات المتجر أو العروض أو مسار الدفع.

### نصائح

ابدأ بمسار الشراء أو الدفع أولًا لأنه غالبًا يكشف أوضح نقاط تعطّل المبيعات.

### أخطاء شائعة

الاعتماد على مسار واحد فقط، أو تجاهل نسبة التسرب بين الخطوات، أو إجراء تغييرات كثيرة قبل التأكد من موضع المشكلة.
