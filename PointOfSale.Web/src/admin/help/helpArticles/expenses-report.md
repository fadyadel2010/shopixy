# Expenses Report

## English

### Overview

This page helps you review spending over a selected period. It shows total expenses, approved expenses, pending expenses, detailed lines, and category totals. It also lets you print the report or export it to Excel for follow-up.

### When to use this page

Use this page at the end of the day, week, or month when you want to see how much the business spent, which categories are highest, and whether there are expenses still waiting for approval.

### Steps

1. Set the date range you want to review.
2. Add filters like category, payment method, or supplier if needed.
3. Click `Generate Report`.
4. Review the summary cards and expense list.
5. Check category totals to spot large spending areas.
6. Print or export the report when you need to share it.

### Tips

Run this report regularly so unusual expense increases are noticed early.

### Common mistakes

Using the wrong date range, forgetting approval filters, or sharing the report before confirming the latest entries are included.

## العربية

### نظرة عامة

تساعدك هذه الصفحة على مراجعة المصروفات خلال فترة محددة. تعرض إجمالي المصروفات، والمصروفات المعتمدة، والمعلقة، والتفاصيل الكاملة، وإجمالي كل تصنيف. كما تتيح لك طباعة التقرير أو تصديره إلى Excel للمشاركة والمتابعة.

### متى تستخدم هذه الصفحة

استخدم هذه الصفحة في نهاية اليوم أو الأسبوع أو الشهر عندما تريد معرفة حجم الإنفاق، وأي التصنيفات الأعلى تكلفة، وهل توجد مصروفات ما زالت بانتظار الاعتماد.

### طريقة الاستخدام

1. حدد الفترة الزمنية التي تريد مراجعتها.
2. أضف فلاتر مثل التصنيف أو طريقة الدفع أو المورد إذا لزم الأمر.
3. اضغط `Generate Report`.
4. راجع بطاقات الملخص وقائمة الحركات.
5. افحص إجمالي كل تصنيف لمعرفة أماكن الصرف المرتفعة.
6. اطبع التقرير أو صدّره عند الحاجة للمشاركة.

### نصائح

شغّل هذا التقرير بشكل منتظم حتى تلاحظ أي زيادة غير طبيعية في المصروفات مبكرًا.

### أخطاء شائعة

اختيار فترة زمنية خاطئة، أو نسيان فلتر الاعتماد، أو مشاركة التقرير قبل التأكد من إدخال آخر الحركات.
