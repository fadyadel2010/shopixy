# Payment Methods

## English

### Overview

This page controls which payment options appear in your online store. You can enable or disable methods, change the names customers see, arrange display order, add fees or limits, and open the setup area for payment providers that need connection details.

### When to use this page

Use this page when launching a new payment option, hiding a method that causes problems, changing fees, or adjusting which methods appear first during checkout.

### Steps

1. Review the list of available payment methods.
2. Open edit to change names, descriptions, limits, or fees.
3. Open configuration for methods that need provider setup.
4. Save the settings.
5. Enable the method only after configuration is complete.
6. Recheck the order and customer-facing details.

### Tips

Keep payment names simple so customers instantly understand how they can pay.

### Common mistakes

Enabling a method before setup is complete, forgetting checkout order, or adding fees without checking customer impact.

## العربية

### نظرة عامة

تتحكم هذه الصفحة في وسائل الدفع التي تظهر في متجرك الإلكتروني. يمكنك من خلالها تشغيل أو إيقاف الوسائل، وتعديل الأسماء التي يراها العميل، وترتيب الظهور، وإضافة الرسوم أو الحدود، وفتح إعدادات الوسائل التي تحتاج إلى ربط خاص.

### متى تستخدم هذه الصفحة

استخدم هذه الصفحة عند إطلاق وسيلة دفع جديدة، أو إخفاء وسيلة تسبب مشكلات، أو تعديل الرسوم، أو تغيير ترتيب وسائل الدفع داخل صفحة الشراء.

### طريقة الاستخدام

1. راجع قائمة وسائل الدفع المتاحة.
2. افتح التعديل لتغيير الاسم أو الوصف أو الحدود أو الرسوم.
3. افتح الإعدادات الخاصة للوسائل التي تحتاج إلى ربط.
4. احفظ التغييرات.
5. فعّل الوسيلة فقط بعد اكتمال إعدادها.
6. راجع ترتيب الظهور وما يراه العميل.

### نصائح

اجعل أسماء وسائل الدفع واضحة وبسيطة حتى يفهم العميل طريقة الدفع بسرعة.

### أخطاء شائعة

تفعيل وسيلة قبل إنهاء إعدادها، أو تجاهل ترتيب الظهور، أو إضافة رسوم بدون مراجعة أثرها على تجربة العميل.
