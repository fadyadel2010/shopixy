# Promotions

## English

### Overview

This page manages automatic offers that apply without a coupon code. It is useful for product or category promotions, scheduled discount windows, and competing offers where priority and exclusivity decide which discount wins at checkout.

### When to use this page

Open this page when you want to launch a storewide offer, discount a specific product line, plan a weekend campaign, or control how overlapping offers behave in the storefront.

### Steps

1. Review the current promotions and summary statistics.
2. Click add to create a new offer.
3. Set the name, description, discount type, and discount value.
4. Choose the scope, such as product or category.
5. Add dates, priority, and any order limits.
6. Save the promotion and monitor its status.

### Tips

Use clear dates and priority settings so overlapping offers behave the way you expect.

### Common mistakes

Creating conflicting offers, forgetting the time window, or leaving scope too broad for the intended campaign.

## العربية

### نظرة عامة

تُستخدم هذه الصفحة لإدارة العروض التلقائية التي تطبق بدون كود خصم. وهي مناسبة لعروض المنتجات أو الأقسام، والعروض المجدولة، والحالات التي تتداخل فيها أكثر من حملة ويحدد فيها الترتيب أو الحصرية أي خصم يتم تطبيقه.

### متى تستخدم هذه الصفحة

افتح هذه الصفحة عندما تريد إطلاق عرض على المتجر، أو تخفيض خط منتجات معين، أو إعداد حملة نهاية أسبوع، أو التحكم في سلوك العروض المتداخلة داخل المتجر الإلكتروني.

### طريقة الاستخدام

1. راجع العروض الحالية وملخص الإحصائيات.
2. اضغط إضافة لإنشاء عرض جديد.
3. حدد الاسم والوصف ونوع الخصم وقيمته.
4. اختر نطاق التطبيق مثل منتج أو قسم.
5. أضف التواريخ والأولوية وأي حدود مطلوبة.
6. احفظ العرض وراقب حالته.

### نصائح

استخدم تواريخ واضحة وأولوية صحيحة حتى تعمل العروض المتداخلة كما تتوقع.

### أخطاء شائعة

إنشاء عروض متعارضة، أو نسيان فترة التشغيل، أو ترك نطاق العرض أوسع من الهدف الفعلي للحملة.
