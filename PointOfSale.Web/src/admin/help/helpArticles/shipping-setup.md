# Shipping Setup

## English

### Overview

This page is the main hub for all shipping operations. It brings together carrier connection status, customer-facing shipping options, shipment monitoring, and shipping health checks so the store can manage delivery from one place.

### When to use this page

Use this page when setting up delivery options for checkout, connecting shipping partners, reviewing live shipments, or checking whether shipping integrations are working properly.

### Steps

1. Start in the configuration tab to review connected carriers.
2. Add or edit the shipping options customers see at checkout.
3. Refresh the page after any major change.
4. Move to the shipments tab to track current delivery records.
5. Open the health tab to inspect connection or sync issues.
6. Update settings whenever rates, carriers, or delivery rules change.

### Tips

Review configuration and shipment results together so checkout options match what operations can actually deliver.

### Common mistakes

Adding customer options before confirming carrier readiness, ignoring the health tab, or forgetting to refresh after changes.

## العربية

### نظرة عامة

هذه الصفحة هي المركز الرئيسي لكل ما يتعلق بالشحن. تجمع في مكان واحد حالة ربط شركات الشحن، وخيارات الشحن التي تظهر للعميل، ومتابعة الشحنات، وفحص صحة التكامل حتى تتم إدارة التوصيل من شاشة واحدة.

### متى تستخدم هذه الصفحة

استخدم هذه الصفحة عند إعداد خيارات الشحن في صفحة الدفع، أو ربط شركات الشحن، أو مراجعة الشحنات الجارية، أو التأكد من أن تكامل الشحن يعمل بشكل صحيح.

### طريقة الاستخدام

1. ابدأ من تبويب الإعدادات لمراجعة شركات الشحن المتصلة.
2. أضف أو عدّل خيارات الشحن التي يراها العميل في المتجر.
3. حدّث الصفحة بعد أي تغيير مهم.
4. انتقل إلى تبويب الشحنات لمتابعة السجلات الحالية.
5. افتح تبويب الصحة لمراجعة مشاكل الاتصال أو المزامنة.
6. عدّل الإعدادات عند تغير الأسعار أو الشركات أو قواعد التوصيل.

### نصائح

راجع الإعدادات مع نتائج الشحن الفعلية حتى تتطابق خيارات المتجر مع قدرة التشغيل الحقيقية.

### أخطاء شائعة

إضافة خيارات للعميل قبل التأكد من جاهزية شركة الشحن، أو تجاهل تبويب الصحة، أو نسيان التحديث بعد التعديلات.
